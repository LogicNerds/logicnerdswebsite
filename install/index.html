About the (RP) labels

Every field a pack adds has a label ending in (RP), for “report pack.” Most orgs already have fields with ordinary names like “Open Opportunities,” and two fields with the same label make reports and filters confusing fast. The (RP) suffix keeps pack fields easy to spot. The API names all start with LNRP_ for the same reason.

Relabeling a field

If you'd rather not see (RP), you can change the label without breaking anything. The reports reference the API name, which doesn't change.

Go to Setup › Object Manager, open the object, then Fields & Relationships. Click the field, click Edit, change the Field Label, and save. Check that the new label doesn't match a field you already have.
